# 歴史的音源 邦楽ファインダー

国立国会図書館デジタルコレクション「歴史的音源」のうち、**インターネット公開（保護期間満了）**の邦楽の録音（約2,600件）を、曲名・演奏者・ジャンルで探せる一覧です。民謡、端唄・小唄・俗曲、長唄、清元・常磐津・新内、義太夫、地歌・箏曲、尺八、雅楽など。

- ページ：`index.html`（データ込みの1ファイル）
- データ：`data.csv`
- 作り方：`rekion_catalog.py`（デジタルコレクションの検索で、コレクション「歴史的音源」・インターネット公開に絞り、ジャンル名で検索）

## 注意

- 「インターネット公開（保護期間満了）」の資料は、手続きなしで二次利用できると国立国会図書館が案内しています。録音（実演・レコード）の権利は切れています。
- 「作者の没年を確認」の印は、作詞・作曲者の名がある新作の曲です。曲そのものの著作権は、日本では1967年以前に亡くなった作者のものなら切れています。それ以後の作者なら使えません。
- ジャンルは検索語による大まかな分類で、関係のない録音が混ざることがあります。検索語にかからない録音は入っていません。
- 書誌情報の出典：国立国会図書館デジタルコレクション（https://dl.ndl.go.jp/）。2026年10月時点。
